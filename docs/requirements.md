# System Requirements

## 1. Project Information

**Project Name:** Smart Mushroom Cultivation Management System

**Objective:** To develop a smart mushroom cultivation management system with rental and remote monitoring features.

## 2. User Roles

* Administrator
* Farm Operator
* Customer

## 3. Functional Requirements

### 3.1 Administrator

* Manage user accounts and permissions.
* Manage cultivation rooms and trays.
* Manage rental packages and pricing.
* Manage IoT devices and camera configurations.
* View and export system reports.

### 3.2 Farm Operator

* Manage cultivation rooms and trays.
* Assign trays to customers.
* Monitor temperature, humidity, and CO2 levels.
* Control cultivation equipment.
* Update cultivation progress and harvest records.
* Receive environmental alerts.

### 3.3 Customer

* Register and sign in.
* Browse available trays and rental packages.
* Rent cultivation trays.
* Monitor rented trays and environmental conditions.
* View camera feeds when available.
* Receive notifications and request harvest collection or delivery.

## 4. Non-Functional Requirements

* Performance: The system should respond quickly to user requests.
* Usability: The interfaces should be easy to use.
* Security: Authentication and role-based authorization must be implemented.
* Scalability: The system should support additional rooms, trays, users, and devices.
* Availability: The system should be accessible through the Internet.

## 5. Initial Implementation Scope

The team will prioritize authentication, room and tray management, rental management, and environmental monitoring. Advanced IoT and camera functions may initially use simulated data if physical devices are unavailable.
