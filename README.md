# Smart Mushroom Cultivation Management System

## 1. Project Overview

Building a smart mushroom cultivation management system with rental and remote monitoring features.

## 2. Project Objectives

* Manage mushroom cultivation rooms and trays.
* Manage rental packages and customer rentals.
* Monitor temperature, humidity, and CO2 levels.
* Track cultivation progress and harvest schedules.
* Provide remote monitoring for customers.

## 3. User Roles

* Administrator
* Farm Operator
* Customer

## 4. Main Modules

* Authentication and Authorization
* Room and Tray Management
* Rental Management
* IoT Environmental Monitoring
* Camera Monitoring
* Harvest and Notification Management
* Testing and Reporting
