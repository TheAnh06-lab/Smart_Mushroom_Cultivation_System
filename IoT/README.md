# IoT Module

## 1. Introduction

This module collects and monitors environmental data for the Smart Mushroom Cultivation System using IoT devices and sensors.

## 2. Main Functions

* Collect temperature data.
* Measure humidity levels.
* Monitor environmental conditions in mushroom cultivation areas.
* Send sensor data to the backend server.
* Support remote monitoring of mushroom cultivation conditions.
* Detect abnormal environmental conditions and send alerts.

## 3. Hardware Components

* ESP32 or ESP8266 microcontroller.
* Temperature and humidity sensor (DHT11 or DHT22).
* Wi-Fi connection.
* Other sensors depending on system requirements.

## 4. Technologies

* Arduino IDE.
* C/C++ for microcontroller programming.
* MQTT or HTTP for data transmission.

## 5. Development Tasks

* Connect sensors to the microcontroller.
* Read temperature and humidity data.
* Send data to the backend API or MQTT broker.
* Test sensor accuracy and data transmission.
* Troubleshoot hardware and communication errors.

## 6. Team Responsibilities

The IoT member is responsible for developing the sensor system, collecting environmental data, and transmitting it to the Smart Mushroom Cultivation System.
