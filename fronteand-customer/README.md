# Frontend Customer

## 1. Introduction

This module provides the customer interface for the Smart Mushroom Cultivation System.

## 2. Main Functions

* Register and log in to the system.
* View mushroom cultivation tray information.
* Register for tray rental services.
* Track rental orders and tray status.
* Monitor cultivation conditions and environmental data.
* View rental history and personal information.

## 3. Technologies

* HTML
* CSS
* JavaScript

## 4. Development Tasks

* Design the customer homepage.
* Build registration and login pages.
* Create tray rental and order tracking pages.
* Connect the interface to the backend API.
* Test the interface and fix errors.

## 5. Team Responsibilities

The frontend-customer member is responsible for developing and maintaining the customer interface.
